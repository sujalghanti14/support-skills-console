Validate a triage record

When a new ticket arrives, the triage skill decides its category, which team gets it, and how urgent it is. This tool checks that decision follows the company's routing rules before the ticket is assigned.

How to use this
  • Paste the JSON the triage skill produced (or press Load example).
  • Green = the record is consistent and can be routed.
  • Red = something doesn't match the rules, e.g. an unknown team, or an outage that isn't marked urgent. Each problem is listed.

Check a reply draft

Catches the mistakes that matter before a reply is sent: a refund or price that isn't in the current policy, money written in words, and phrases that break the company's tone of voice.

How to use this
  • Paste the reply you're about to send (or press Load example to see a bad one).
  • If the reply mentions a number from the customer's own account, like the exact amount they were charged, type it in the second box so it isn't flagged.
  • Press Show current policy to see the rules every figure is checked against. They're read live, so policy updates apply immediately.

    

  


  
  

    

      
Build the weekly QA report

      
Each week a sample of closed tickets is scored against a quality rubric. Paste those scores here and you get the pass rate and the recurring problems to coach the team on.

    

    

      How to use this
      
    
        
  • Paste the grades (one JSON object per ticket), or press Load example.
    • 
        
  • A ticket passes with an average score of 3 or more out of 4, no score of 1, and no serious mistake such as a wrong refund figure.
    • 
        
  • A pattern is a problem seen on 2 or more tickets. Press Download report to share it.

Is this a known issue?

      
When a customer reports a bug, search the product changelog first. If it's already known, give them the workaround. If it's new, it needs a write-up for engineering.

    

    

      How to use this
      
    
        
  • Describe the problem in a few words, e.g. "CSV export times out", and press Search.
    • 
        
  • KNOWN_OPEN = not fixed yet; share the workaround. FIXED = fixed in that version; the customer may need to update.
    • 
        
  • Results are suggestions. Check it's really the same problem (same feature, same device) before replying.
